# 开源方案对比

| 方案 | 覆盖 | 与本项目差异 |
| --- | --- | --- |
| Nav2 | 导航/恢复行为 | 只做单机导航；本项目在它之上做安全出口与编队调度 |
| slam_toolbox | 2D SLAM | 只建图；本项目增加冻结+哈希共享给第二台狗 |
| AMCL | 已知地图定位 | 需正确初始位姿；本项目增加收敛准入与重定位服务 |
| Open-Vocabulary detectors | 通用检测 | 需大算力；本项目用 YOLO-ONNX + 深度投影，缺失时 fail closed |
| MoveIt 2 | 机械臂规划 | MyArm-2 固件只有动作组 ASCII，无规划接口；本项目只用语义动作 |
| Open-RMF | 多机器人调度 | 面向楼宇电梯/门禁；本项目为双狗串行交接的轻量协调器 |

## 结论

本项目不做通用框架，只做“两条 Lite3 + 已知地图 + 串行交接”的最小闭环：
安全链、冻结地图共享、定位准入、动作组语义、编队状态与报告。
通用框架可替换其中任意模块，但必须保持唯一 `/cmd_vel` 出口与 fail-closed 原则。
