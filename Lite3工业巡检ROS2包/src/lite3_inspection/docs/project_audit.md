# 项目审计

## 范围

仓库 `Lite3工业巡检ROS2包` 工作空间，含双狗协同（lite3_01_mapping、
lite3_02_picking、fleet_manager、fleet_interfaces）与遗留单狗栈
（lite3_inspection）。

## 结论摘要

- 安全链完整：所有自主速度经 mux 仲裁、guard 限幅，唯一 `/cmd_vel` 发布者。
- 感知/深度/TF 缺失时 fail closed，不产生假检测或假 3D 点。
- 机械臂只接受语义动作，坐标与原始帧被拒绝；无完成 ACK 的语义被如实暴露。
- 双狗地图共享采用“冻结 + SHA256”，避免 Dog 2 在移动地图上定位漂移。
- Dog 2 准入依赖 AMCL 收敛，初始位姿必须测绘，避免“找不到自己”。
- 编队层有作业区预约、交接超时、急停传播与报告。

## 风险

| 风险 | 缓解 |
| --- | --- |
| 初始位姿错误 → Dog 2 永不收敛 | 双准入 + `/dog2/relocalize` + 文档 |
| 地图未冻结 → 定位漂移 | 哈希校验，未冻结不转发 |
| 动作组无 ACK | 保守忙窗，禁止假完成 |
| 两狗话题冲突 | `/dog1`、`/dog2` 前缀隔离 |
| 占位坐标误用 | 所有配置默认空/占位并标注 SURVEYED |

- 未做仿真回归。
