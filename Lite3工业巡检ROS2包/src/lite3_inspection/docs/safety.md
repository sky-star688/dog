# 安全边界与上线门槛

## 硬性规则

1. `/cmd_vel` 只有 `cmd_vel_guard` 一个发布者；发现第二发布者立即停止。
2. 任何自主运动前 `motion_enable=true`；急停、定位丢失、任务结束必须置 false。
3. 速度超时 0.25 s 输出零，不保持最后命令。
4. 非有限速度值整条拒绝，不转发部分轴。
5. 机械臂 STOP 始终允许且优先；`$DGS`/`$DJR`/`$DST` 无完成 ACK。
6. 地图未冻结或哈希不匹配时 Dog 2 不得导航。
7. AMCL 未收敛时 Dog 2 不得接受目标。
8. 巡检狗与占用作业区最小距离 5 m；两狗最小间距 3 m。
9. 任一狗急停 → 全编队急停。

## 上线门槛（必须全部满足）

- [ ] 阶段 A（静态话题/TF/相机/单发布者）通过
- [ ] Dog 1 建图完成并冻结，`/shared_map/metadata` 有 sha256
- [ ] Dog 2 `map_verified=true` 且 `localization_status=true`
- [ ] 机械臂空载台架：STOP 有效、组号已录、忙窗已实测
- [ ] OpenMV 只读 → 标定残差合格 → 单次 KMS 人工确认
- [ ] 串行交接 dry-run 完整通过（有人监护、无负载）
- [ ] 硬件急停可在运动范围内立即触发
- [ ] 现场人员监护、运动范围内无人

## 禁止

- 用占位坐标代替现场测绘航点/作业区坐标。
- 用未验证动作组号直接上电动作。
- 把“串口写入成功”当成“动作完成”。
- 在无急停、无监护的情况下执行自动抓取。
